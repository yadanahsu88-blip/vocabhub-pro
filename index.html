⌨️ Shortcuts & Quick Guide

🇺🇸 English

• Enter or →: Go to next card / next item

• ← (Left Arrow): Previous flashcard

• Enter: Submit answer in Typing Drill

• Backspace / Alt + ←: Go back to previous screen

• Esc: Close open popup / modal

• Speed Controls: Adjust voice playback speed across all audio buttons (Slow / Normal / Fast)

• Auto Cleanup: Stops audio & mic automatically when leaving/switching sections

🇲🇲 မြန်မာ

• Enter သို့မဟုတ် →: နောက်တစ်ခုသို့ သွားရန်

• ← (Left Arrow): Flashcards ထဲတွင် ရှေ့ကတ်သို့ ပြန်ရန်

• Enter: Typing Drill ထဲတွင် အဖြေ တန်းစစ်ရန်

• Backspace / Alt + ←: ရှေ့စာမျက်နှာသို့ ပြန်သွားရန်

• Esc: ပွင့်နေသော Popup / Modal ပိတ်ရန်

• Speed Controls: အသံနားထောင်နိုင်သော နေရာအားလုံးတွင် အနှေးအမြန် ချိန်နိုင်သည်

• Auto Cleanup: Section ပြောင်းခြင်း သို့မဟုတ် ထွက်ခြင်းတွင် အသံနှင့် mic ကို အလိုအလျောက် ပိတ်ပေးသည်

🇹🇼 中文

• Enter 或 →：前往下一張或下一題

• ← (左方向鍵)：單字卡上一張

• Enter：打字練習送出答案

• Backspace / Alt + ←：返回上一頁

• Esc：關閉彈出視窗

• 語音速度：所有語音播放皆可調整快慢（慢速 / 正常 / 快速）

• 自動清理：切換區塊或離開頁面時自動停止語音與麥克風
